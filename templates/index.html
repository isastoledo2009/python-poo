O que é o pyton?

Python é uma linguagem de programação criada para ser simples e fácil de entender.

Possui sintaxe organizada e parecida com a linguagem humana.

É muito utilizada no desenvolvimento de sistemas, sites, automações e inteligência artificial.

Para que serve o Pyton?

Desenvolvimento de sites e sistemas web. Criação de jogos.
Automação de tarefas.
Desenvolvimento de aplicativos.
Análise de dados.
Inteligência Artificial e Machine Learning.
Criação de APIs e Back End.

Vantagens de usar Python na vida profissional

Fácil de aprender e utilizar.
Muito usada no mercado de trabalho.

O que é POO?

Conceito

POO é uma forma de programar baseada em objetos.
Os objetos representam elementos do mundo real.
Cada objeto possui:
Atributos → características.
Métodos → ações ou funções.
Exemplo:

Objeto: Carro
Atributos: cor, modelo, ano.
Métodos: ligar, acelerar, frear.

Qual a vantagem de usar POO?

Organização melhor do código.
Facilidade para manutenção.
Reutilização de código.
Maior segurança e controle das informações.
Projetos mais fáceis de expandir.
